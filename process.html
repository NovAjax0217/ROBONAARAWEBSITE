THE PROCESS

From the first crazy idea to the final competition run, every part of AJAX is built through teamwork, testing and a lot of problem solving.

01 // IDEATE

IDEATE

Every build starts with an idea. We brainstorm, experiment and figure out what AJAX needs to do before turning the concept into something real.

02 // DESIGN

DESIGN

We turn ideas into actual designs, planning the robot's structure, mechanisms and systems while making sure everything works together.

03 // BUILD

BUILD

Components become a robot. We assemble AJAX, connect the hardware and solve the unexpected problems that appear along the way.

04 // CODE

CODE

Code gives AJAX its brain. We program the robot's behaviour, controls and systems so it can respond quickly and reliably on the field.

05 // TEST

TEST

Nothing goes straight to competition. We test, break, fix and test again until AJAX can handle different situations without giving up.

06 // OPTIMISE

OPTIMISE

Small improvements make a big difference. We analyse performance, improve our systems and remove weaknesses from both the robot and our strategy.

07 // COMPETE

COMPETE

Time to put everything to the test. We take AJAX onto the field, work together under pressure and give ROBONAARA everything we've got.
